## 사용자 요청 (원문 요지)

1. 가사 검색이 불안정 — 유명한 곡도 못 찾거나, 같은 곡이 찾아졌다 말았다 함(예: 아이리 칸나 최종화), 다른 곡이 연결됨.
   알송에 없으면 탐색 수단을 늘리고, 알송에 있는 곡은 확실히 찾을 것. 목표는 "최대화".
2. 가사 찾는 시간이 너무 김 — 적중률을 떨어뜨리지 않는 선에서 최적화.
3. 싱크 없는 가사로 자동 싱크가 가능하면 하고, 불가능하면 포기하되 본문만이라도 보여 줄 것
   (메인 창은 마우스 스크롤, 플로팅 창은 Alt+Z/Alt+X).
4. Alt+A/D 방향 맞바꾸기, 싱크 보정 ±10초 제한 제거, Alt+S로 원래 싱크.
5. 외국어만 있는 가사에 한글 발음 표기, 표시 방식 선택(번역/발음), 영어는 둘 다 제외. 기계 번역이 제대로 되는 걸 본 적 없음.
6. 번역 모델 교체(더 작고 품질 좋은 최신 모델). 곡 중간에 번역을 켜고 끄면 즉시 반영.
7. 판정은 정답표 대신 **LLM(Claude)이 결과를 직접 읽고** 할 것 — 음악 카드 같은 휴리스틱을 정답 기준으로 쓰지 말 것.
   참고 재생목록: `PL-gF1AzHbnB1NmbIKnCWNKWir8xqaL7CU`(56곡), `PL-gF1AzHbnB1gt88pgVUdLiiuyyXuiXCe`(482곡).

## 2026-10-04 밤 — 텍스트 가사 + 자동 싱크 + 가사 저장 (사용자 수면 중 자율 작업)

### 사용자 명세 (요지 — 원문은 대화 기록)
1. 싱크 가사를 못 찾으면 텍스트 가사라도 구한다. 구글링일 필요는 없고, **반드시 그 곡의 가사**여야 한다 — 영상 제목·
   설명란·저작권(음악 카드) 등 모든 정보를 쓴다. 싱크 제약이 사라진 만큼 정확도는 더 높아야 한다.
2. 1차 싱크 = 곡 전체 시간에 가사 줄을 같은 속도로 배치(소리 연산 없음). 그동안 2차 정밀 싱크(소리 ↔ 텍스트 발음
   매칭)를 계산한다. 게스트 로컬 저장본은 가사+싱크를 저장해 다음부터 즉시.
3. 저장은 게스트 로컬 재생목록(playlists.json)의 곡만. 계정 연동 재생목록은 저장하지 않는다. 저장한 가사는 다른 가사로
   덮어쓰기·가사만 삭제 가능. 로컬에서 재생목록/영상이 사라지면 가사도 삭제. **저장되니 속도는 덜 중요하다는 판단은
   틀렸다** — 새 곡·새 재생목록이 계속 생기므로 탐색·연산·번역은 항상 실시간으로 준비돼 있어야 한다.
- 번역은 웹 번역(사용자 검증 완료). 번역 없는 가사에는 웹 번역을 더한다. 가사 선택 우선순위는 "번역 있음/없음"보다
  **진짜 그 곡의 가사인지**가 최우선. 잘 되면 싱크 가사도 더 엄격히 — 틀린 싱크 가사보다 텍스트 가사 + 자동 싱크.
- 가사 종류 표시(번역된 싱크 / 미번역 싱크+우리 번역 / 미싱크 번역 / 미싱크 미번역): 플로팅 창 X, 메인 앱에 작게,
  마우스를 움직일 때만 우상단에 잠깐(전체화면 아니어도).
